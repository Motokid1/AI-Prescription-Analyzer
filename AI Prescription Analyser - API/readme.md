# AI Prescription Analyzer Backend

FastAPI backend for analyzing prescriptions using OCR, LangChain Core, Groq LLM, and HuggingFace embeddings.

## Features

- Upload prescription PDF/image
- Extract text using PDF parser or OCR
- Extract medicine name, dosage, frequency, duration, instructions
- Explain medicines in simple language
- Generate daily medicine schedule
- Detect missing or unclear prescription details
- Add safety disclaimer
